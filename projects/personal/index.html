WHY / 解决什么问题

工具之间的重复，不该变成每天的工作。

01

一条记录，多处查看

日历、当天清单和首页共享同一条安排的投影；保留历史记录及原ID。

02

把跟进留在上下文

集中管理投递状态、相关简历和项目事项；查看历史，减少信息散落。

03

本机保存，多端访问

私有部署与认证边界分开设计，支持备份恢复；公开展示页不访问私人服务。

MY CONTRIBUTION / 我的贡献

从个人需求，
到可持续使用的工具。

从日常使用出发定义安排、投递、简历和项目的关系；提出“只记录一次”的统一安排逻辑，参与界面迭代、迁移需求与数据保留规则的验证。

项目由吴桓提出需求、设计规则并与AI协作实现。代码与文档包含AI辅助产出，不将其表述为全部手工独立开发。

HOW / 实现与取舍

实现方式

使用 Vite 与原生 JavaScript 构建前端，Node.js 与 PocketBase 提供本机服务和私有数据存储；通过统一投影组织安排，支持备份恢复及认证访问。跨设备访问依赖本人私有网络和本机在线。

公开展示的边界

此页是独立的脱敏展示，不是私人工作台的在线副本。页面示例均为合成内容；不提供真实账户、原始报告或个人日程访问。功能说明基于本机项目，不能据此承诺招聘筛选或任务实际完成。

REUSABLE / 可复用方法

个人工作台负责组织与推进，简历工作台负责理解作品和岗位表达。两者的私人数据均不随展示页公开。
