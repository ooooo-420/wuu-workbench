# wuu 个人工作台

[打开公开展示页](https://wuu-personal-workbench-showcase.peachy-horse-6031.chatgpt.site)

将每日安排、实习投递、简历版本、项目与金融资讯集中管理。减少重复记录，让今天做什么、下一步跟进什么更清楚。

## 我的贡献

从日常使用出发定义安排、投递、简历和项目的关系；提出“只记录一次”的统一安排逻辑，参与界面迭代、迁移需求与数据保留规则的验证。

项目为需求驱动、AI辅助协作实现；不宣称全部代码为手工独立开发。

## 实现

使用 Vite 与原生 JavaScript 构建前端，Node.js 与 PocketBase 提供本机服务和私有数据存储；通过统一投影组织安排，支持备份恢复及认证访问。跨设备访问依赖本人私有网络和本机在线。

此目录仅发布独立展示源代码，所有示例为合成内容。双击 index.html 即可查看示意；原版私有服务与数据未公开。
