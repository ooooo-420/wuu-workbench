# wuu 简历工作台

[打开公开展示页](https://wuu-resume-workbench-showcase.peachy-horse-6031.chatgpt.site)

围绕真实使用需求设计：先理解作品，再对照岗位，保留具体分析动作；用知识库和版本历史，让下一次修改接着上一次往前走。

## 我的贡献

定义金融与战略类岗位的证据要求、独立编写作品的归属规则、STAR和双语对齐原则；持续用实际修改稿反馈改进选材、检索与版本记忆。

项目为需求驱动、AI辅助协作实现；不宣称全部代码为手工独立开发。

## 实现

本机服务使用 Node.js、SQLite 与 Markdown Wiki，复用本机 Codex 登录调用在线模型。文件监听负责同步，结构化输出负责生成，引用校验与版本快照负责追溯；Word/PDF 排版独立处理。

此目录仅发布独立展示源代码，所有示例为合成内容。双击 index.html 即可查看示意；原版私有服务与数据未公开。
