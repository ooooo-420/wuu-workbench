WHY / 解决什么问题

简历不应只写“参与研究”。

01

作品 → 证据

将抽取文字分段分析，保存动作、方法、对象、产出、适用岗位和连续原文引用。

02

证据 → 岗位

拆解JD，区分直接匹配、可迁移能力与缺口；用STAR组织证据链，不编造结果。

03

版本 → 下一次

参考同岗位最近版本的框架与选材，再按新JD调整；双语正文和导出样式分别管理。

MY CONTRIBUTION / 我的贡献

从个人需求，
到可持续使用的工具。

定义金融与战略类岗位的证据要求、独立编写作品的归属规则、STAR和双语对齐原则；持续用实际修改稿反馈改进选材、检索与版本记忆。

项目由吴桓提出需求、设计规则并与AI协作实现。代码与文档包含AI辅助产出，不将其表述为全部手工独立开发。

HOW / 实现与取舍

实现方式

本机服务使用 Node.js、SQLite 与 Markdown Wiki，复用本机 Codex 登录调用在线模型。文件监听负责同步，结构化输出负责生成，引用校验与版本快照负责追溯；Word/PDF 排版独立处理。

公开展示的边界

此页是独立的脱敏展示，不是私人工作台的在线副本。页面示例均为合成内容；不提供真实账户、原始报告或个人日程访问。功能说明基于本机项目，不能据此承诺招聘筛选或任务实际完成。
